Frequently Asked Questions

How do I install the browser extension?

Download the ZIP for your browser from the Download section, unzip it, then load it as an unpacked extension. Full instructions are in the Downloads section. Once store listings are live, you'll be able to install with one click from the browser store.

Is my data actually private?

Yes. All PII detection and masking happens 100% locally in your browser. Nothing you type is sent to our servers — in fact we operate no servers for masking at all. See the Privacy Policy for details.

Which AI apps does it protect?

ChatGPT, Copilot, Gemini, Claude, Perplexity, Poe, Groq, Mistral, Cohere, Meta AI, DeepSeek, You.com, Kimi, Qwen, Jina, Phind, and Google AI Chat — 17 platforms in total.

How do I set up the VPN?

Use the one-command installer: node vpn/setup.mjs --host YOUR_VPS_IP. You can get a permanently free server — see the free server guide or the VPN section on the homepage.

Is the VPN really free?

The software is completely free and open source. It runs on any Ubuntu/Debian server — including the permanently free tiers from Oracle Cloud and Google Cloud. See FREE_VPS.md.

Why is a PII type not being detected?

Detection uses confidence scoring to avoid false positives. If a value scores below the threshold, it may pass through. You can also check the interactive demo to test specific formats.
