Features

25+ PII Types

Email, phone, SSN, credit card, passwords, API keys, IPs, crypto wallets, MAC, DOB, passport, license, address, bank, and international formats (UK, India, China, Australia, Canada).

Luhn CC Validation

Credit cards are verified using the Luhn algorithm. Invalid check digits are flagged with reduced confidence, cutting false positives.

Realistic Masking

Switch between placeholder mode [TYPE_N] and realistic fake data mode. Fake data preserves format so AI responses still make sense.

Inline Highlighting

PII is highlighted with colored underlines as you type. Each PII type has a distinct color so you can see exactly what will be masked.

Risk Score & Export

Aggregate 0-100 risk score based on PII sensitivity. Export results as JSON or CSV for auditing and compliance.

100% Local & PWA

All processing in your browser. Installable as a Progressive Web App for offline use. No data ever leaves your machine.

REST API & CLI Server

Start a local REST API with cli.js serve — POST /scrub, POST /scan, GET /rules, GET /health. Integrate PII detection into any pipeline.

Built-in WireGuard VPN

Full network privacy with a native WireGuard VPN — you host the server. Kill switch, key generator, and one-command setup. Learn more →
